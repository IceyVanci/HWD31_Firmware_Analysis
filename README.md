## Introduction

This project aims to provide an AI-assisted reverse-engineering analysis and learning reference for the SIM Lock mechanism of the HWD31 (Speed Wi-Fi NEXT W01). All materials come from public sources; the reverse-engineering work was carried out using OpenCode and DeepSeek Harness connected to DeepSeek V4.1 Flash.

If you are also analysing the HWD31 or researching its SIM Lock mechanism, I hope the documents in this project can help you. The price of private unlock solutions for this device far exceeds the price of the device itself, which I consider wrong. Although the current reverse-engineering analysis still cannot fully explain the SIM Lock mechanism, and the work so far cannot yet reproduce the results of private unlock tools, I hope this open-source project can serve as a stepping stone and foundation for further research.

## Documents

The `docs/` directory contains analysis documents in both Chinese and English: the Chinese edition is in [`docs/zh-CN/`](docs/zh-CN/), and the English edition is in [`docs/en/`](docs/en/).

> These documents are retrospective summaries of the project. The internal evidence documents, firmware images, and research artifacts they reference are not included in this repository. Where the Chinese and English editions differ, the Chinese edition is authoritative.
