## 四、术语

| 术语 | 含义 |
|---|---|
| SIM Lock | 设备的 SIM 网络锁；本项目的目标 |
| NV 0xC546 / 50502 / E0 | 锁记录槽位；包含 hash+salt，共 0x19B（411 B） |
| NV 0xC547 / 50503 / E1 | 第二锁记录槽位；与 E0 共用校验代码，NV 项/槽位不同 |
| `^CARDLOCK` | 锁查询/提交命令；本镜像的 SET 恒拒 |
| `^DATALOCK` | E0 提交口；3 次/启动，可免 `^CARDLOCK` 计次验证候选码 |
| `/dev/nv` | AP 侧 NV 读取节点；12 B 头 + 1024 B 数据 |
| dload | 高通/华为刷写协议；HDLC 帧 + CRC-X25；有硬会话门 |
| five 容器 | 官方升级包格式；17 组件；本地升级有字节级内容锁 |
| nvram.bak | 设备配置备份；逐行 base64 + checksum；可恢复 22 个配置文件 |
| FOTA | 在线更新；CheckNewVersion → filelist → 下载 → 安装/回报 |
| 22 文件写原语 | 通过合法 nvram.bak 恢复，写入 22 个既定配置文件的受控写能力 |
| R1–R4 / R4b | R1 日志、R2 锁命令、R3 非 WAN 执行点、R4 官方基线；R4b=dload 签名引擎 |
